# Panduan Microcopy

## Kosakata baku

| Pakai | Jangan pakai |
|---|---|
| Diproses | Pending, Menunggu, Loading |
| Berhasil | Sukses, Success, Done |
| Gagal | Error, Failed |
| Verifikasi | Autentikasi, OTP (kecuali memang kode) |
| Riwayat Transaksi | History, Log |
| Beli Paket | Top up paket, Purchase |

## Nada

Ramah, singkat, memakai "kamu". Satu kalimat satu ide. Beri tahu apa yang terjadi, lalu apa langkah berikutnya.

## Contoh per situasi

| Situasi | Salah | Benar |
|---|---|---|
| Pembayaran berjalan | "Loading..." | "Pembayaran diproses. Jangan tutup halaman ini. Hasilnya muncul otomatis." |
| Menunggu penyedia | (layar diam) | "Menghubungi penyedia pembayaran…" lalu "Menunggu konfirmasi pembayaran…" |
| Verifikasi ulang | "Verifikasi gagal, ulangi." | "Diminta verifikasi ulang. Alasan: demi keamanan, pembelian perlu dikonfirmasi sekali lagi. Pembelian Data 12 GB belum diproses sampai langkah ini selesai." |
| Berhasil | "Transaksi sukses" | "Pembelian berhasil. Kuota Data 12 GB sudah ditambahkan. Sisa kuota kamu sekarang 13,2 GB." |
| Gagal | "Terjadi kesalahan" | "Pembayaran belum berhasil. Kamu bisa mencoba lagi atau membuka Bantuan." |
| Riwayat kosong | "Tidak ada data" | "Belum ada transaksi. Mulai dari Beli Paket." |
| Filter tanpa hasil | "Kosong" | "Belum ada transaksi yang cocok dengan filter ini." |
| Tombol bayar | "OK" | "Bayar Rp65.000" |
| Tombol lanjut verifikasi | "Lanjut" | "Konfirmasi dan lanjut ke pembayaran" |

## Larangan

- Jangan menjanjikan hal yang tidak diketahui sistem (misalnya "saldo pasti tidak terpotong").
- Jangan memakai singkatan teknis di layar pengguna.
- Jangan menyalahkan pengguna ("Anda salah memasukkan...").
- Jangan memakai huruf kapital semua untuk menekankan.
